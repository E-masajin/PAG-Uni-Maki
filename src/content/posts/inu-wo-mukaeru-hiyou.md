「犬を飼いたい」と思ったとき、最初に立ちはだかるのはたいていお金の話です。

かわいさで決めてしまってから家計が苦しくなるのが、犬にとっても飼い主にとっても一番つらい。だからここでは、うちが実際に払ってきた金額をもとに、**お迎え時にまとまって出ていくお金**と、**その後ずっとかかり続けるお金**を分けて書きます。

金額はあくまで目安です。地域・犬種・体の大きさで大きく変わりますし、動物病院の料金は自由診療なので病院ごとに違います。「だいたいこのくらいの桁になる」という感覚をつかむために読んでください。

## お迎えのときに一度だけかかるお金

### 生体価格：0円〜50万円

一番ぶれる項目です。迎え方によってまったく変わります。

| 迎え方 | 目安 |
| --- | --- |
| ペットショップ | 20万〜50万円 |
| ブリーダーから直接 | 15万〜40万円 |
| 保護犬（譲渡） | 3万〜6万円程度の譲渡費用 |
| 知人から譲り受ける | 0円のことも |

保護犬の譲渡費用は「犬の値段」ではなく、それまでにかかったワクチン代・不妊手術代・検査代の実費負担です。無料ではないことに驚く人がいますが、団体が立て替えていた医療費だと考えると納得できるはずです。

迎え方ごとの違いは長くなるので、別の記事で詳しく書いています。

### 最初にそろえる用品：3万〜7万円

初日から必要になるものだけでも、意外とまとまります。

- クレート／サークル：5,000〜15,000円
- 食器・給水器：2,000〜5,000円
- トイレトレー＋シーツ：3,000〜6,000円
- 首輪・リード・胴輪：5,000〜12,000円
- ベッド、タオル類：3,000〜8,000円
- ケア用品（ブラシ・爪切り・シャンプー）：3,000〜8,000円

うちは最初、かわいさで選んだベッドをまったく使ってもらえませんでした。**寝床とおもちゃは、最初から良いものを買わなくていい**と思います。その子の好みが分かってから買い直したほうが、結果的に無駄が少なくなります。

### 医療・登録関係：2万〜10万円

- 混合ワクチン：1回 5,000〜10,000円（子犬期は複数回）
- 狂犬病予防注射：3,500円程度＋自治体への登録手数料 3,000円程度
- 健康診断・便検査：3,000〜10,000円
- 避妊・去勢手術：3万〜7万円（体格と性別で変わります）
- マイクロチップ装着・登録：5,000〜8,000円程度

犬の飼い主には、**狂犬病予防注射と自治体への登録が法律で義務づけられています**（狂犬病予防法）。これは任意ではありません。2022年6月以降、販売される犬猫にはマイクロチップの装着が義務化されており、迎えたあとに飼い主情報へ変更登録する手続きも必要です。

## 毎月かかり続けるお金

ここからが本番です。**犬との暮らしは、初期費用よりランニングコストで効いてきます。**

| 項目 | 月額の目安 |
| --- | --- |
| フード | 3,000〜10,000円 |
| おやつ | 1,000〜3,000円 |
| トイレシーツ | 1,500〜3,000円 |
| ペット保険 | 2,000〜5,000円 |
| トリミング | 5,000〜10,000円（月1回の場合） |
| おもちゃ・消耗品 | 1,000〜3,000円 |

小型犬でトリミングが不要な犬種なら **月1万円前後**、トリミングが必要な犬種なら **月2万円前後**が一つの目安です。中型・大型犬になるとフード代が跳ね上がります。

年に一度、まとまって出ていくお金もあります。

- 混合ワクチンの追加接種：5,000〜10,000円
- 狂犬病予防注射：3,500円程度
- フィラリア・ノミダニ予防：1万〜2万円（春〜秋の数か月分）
- 健康診断：1万〜3万円

## 見落とされがちな、いちばん大事な項目

### 病気やけがの治療費

犬に公的な健康保険はありません。**かかった費用は全額自己負担**です。

金額の桁が変わるのはここです。誤飲による開腹手術で20万〜40万円、椎間板ヘルニアの手術で30万〜50万円といった話は、決して珍しくありません。

ペット保険に入るか、入らずに「その分を毎月貯める」か。どちらでもいいと思いますが、**どちらもやっていない状態だけは避けてください**。うちは保険に入りつつ、別に月5,000円の医療用の積立をしています。

### 預けるお金

旅行や出張、入院。自分が家を空けるときのことです。ペットホテルは1泊3,000〜8,000円、ペットシッターは1回3,000〜5,000円ほど。頼れる家族が近くにいない場合、これは確実に発生する費用として見ておいたほうがいいです。

### 生涯でいくらになるか

小型犬の平均寿命はおおよそ14〜15年です。月1万5,000円としても、15年で **約270万円**。初期費用と医療費を足すと、**300万円前後**を見込んでおくのが現実的です。

大きな数字ですが、月あたりで考えれば携帯代と光熱費の間くらいの支出です。**問題は総額の大きさではなく、その支出が15年続くことに耐えられる家計かどうか**だと思っています。

## それでも迎えると決めた人へ

お金の話ばかりしてしまいましたが、脅かしたいわけではありません。

うちがうにを迎えたとき、正直ここまで細かく計算していませんでした。あとから「知っておけばよかった」と思ったから、これから迎える人には先に渡しておきたかっただけです。

必要なのは、余裕のある家計ではなく、**急な出費に対応できる備えがあること**。それさえ用意できるなら、あとは迎える日を楽しみに待ってください。
