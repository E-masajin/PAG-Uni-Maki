# 写真の置き場所

ここに写真を置いて、コード側のパスを差し替えると反映されます。
枠の比率は決まっているので、**推奨サイズに近い比率で書き出す**とトリミングされません。

| フォルダ | 用途 | 比率 | 推奨サイズ（長辺） | 参照する場所 |
| --- | --- | --- | --- | --- |
| `dogs/` | うに・まきのポートレート | 4:5 | 1600×2000 | `src/lib/dogs.ts` の `photo` |
| `posts/` | 記事のサムネイル・ヒーロー | 3:2 | 1600×1067 | 各記事の frontmatter `cover` |
| `goods/` | グッズ写真 | 1:1 | 1200×1200 | `src/lib/goods.ts` の `image` |
| （直下） | LP のヒーロー | 4:3 | 2400×1800 | `src/app/page.tsx` の最初の `Photo` |

パスは `/images/dogs/uni.jpg` のように `/public` を除いた形で書きます。

## 写真がまだないとき

`photo` / `cover` / `image` を未設定のままにしておくと、
「PHOTO ／ 撮影予定：〜」と書かれた枠が表示されます。
レイアウトは本番と同じ比率なので、あとから差し替えてもズレません。

## 撮るときのメモ

- 2匹の目にキャッチライトが入っていること
- 背景が散らかっていないこと
- できるだけ自然光で
- 「かわいい顔」より「その子らしい仕草」を優先
- 1記事につき最低3枚、うち1枚は2匹が同じフレームに入ったもの

露出・ホワイトバランス・水平の補正はしてかまいませんが、
フィルターや彩度の強調は、サイト全体の色から浮くので避けてください。
